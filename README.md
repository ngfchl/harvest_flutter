# Harvest

Harvest 是面向 Go Harvest / PT 收割机后端的 Flutter 客户端。它把 PT 站点维护、仪表盘、下载器管理、种子操作、影视资讯、聚合搜索、计划任务、通知、日志排查和客户端更新集中在一个 App 内。

支持平台：

- Web
- Android / iOS
- macOS / Windows / Linux

> 本文按当前代码整理为 APP 使用手册。不同后端版本、账号权限和平台能力会影响部分入口是否显示。

## 快速开始

### 准备后端

使用前需要先有可访问的 Go Harvest 后端服务。客户端登录页需要填写服务器地址，例如：

```text
http://127.0.0.1:8000
https://harvest.example.com
```

建议：

- Web 端优先使用 HTTPS 后端，避免浏览器混合内容限制。
- 移动端和桌面端可以连接局域网、内网穿透或公网后端。
- 如果后端启用了初始化流程，首次登录前需要先完成初始化。

### 首次使用建议

1. 登录或完成后端初始化。
2. 到「设置中心」配置通知、CookieCloud、影视 Token、搜索站点等基础项。
3. 到「站点」添加站点或导入站点配置。
4. 到「下载」添加 qBittorrent 或 Transmission 下载器。
5. 到「任务中心」配置自动签到、站点信息更新、辅种、种子迁移等任务。
6. 到「仪表盘」查看全局数据、服务器状态和趋势图表。

## 初始化后端

当后端尚未初始化时，登录页会自动检测并打开「Go Harvest 初始化」窗口。

初始化配置包含：

- 数据库类型：PostgreSQL 或 SQLite。
- PostgreSQL 地址、端口、数据库名、用户名和密码。
- SQLite 数据库文件，默认 `db/data.sqlite3`。
- 管理员用户名、邮箱和密码。
- JWT Secret，可自动生成。

初始化成功后，客户端会把管理员账号填回登录页。常见失败原因包括数据库不可达、数据库账号权限不足、SQLite 目录不可写、管理员密码过短或 JWT Secret 为空。

## 登录与账号

### 登录

登录页需要填写：

- 服务器地址。
- 用户名。
- 密码。

登录成功后客户端会保存认证状态，并默认进入「仪表盘」。

### 登录历史

客户端会保存历史登录记录。可在登录历史页快速切换服务器和账号。若后端地址、账号权限或 Token 变化，建议重新输入登录信息。

### 切换账号与退出

登录后可通过左侧菜单或头像菜单执行：

- 切换账号：退出当前会话并进入登录历史。
- 退出登录：清理当前认证状态并返回登录页。

## 界面导航

### 主导航

主导航包含：

- 资讯：TMDB 与豆瓣影视资讯。
- 站点：PT 站点列表、状态、签到、辅种和配置管理。
- 仪表：总览看板、服务器资源、上传下载趋势和站点统计。
- 下载：下载器配置、实时速度和种子列表入口。
- 任务：计划任务和执行记录。
- 搜索：影视信息搜索与站点资源搜索。

### 桌面端菜单

桌面宽度下，登录后左侧会显示常驻 `NavigationSidebar` 菜单。菜单包含：

- 数据仪表、全局搜索。
- 资讯中心、站点数据、站点动态。
- 下载管理、任务列表。
- 设置中心、程序更新、应用升级。
- 日志中心、日志浮窗。
- 用户中心、授权管理。
- 服务重启、切换账号、退出登录。

顶部栏最左侧菜单按钮在桌面端用于显示或隐藏常驻菜单；在移动端用于打开抽屉。菜单隐藏时，macOS/Linux 桌面端会在 header 左侧保留红绿灯窗口按钮空间；Web 端不会保留红绿灯空间。

### 移动端与 Web

移动端通过底部导航和左侧抽屉使用主要入口。Web 端不显示本地窗口控制按钮，也不会预留红绿灯位置。

## 资讯

「资讯」页聚合 TMDB 和豆瓣内容。

TMDB 常见入口：

- 正在上映电影。
- 即将上映电影。
- 热门电影。
- 热门剧集。
- 高分电影和剧集。

豆瓣常见入口：

- Top250。
- 热门电影。
- 热门剧集。
- 榜单和标签内容。

影视详情页支持查看简介、评分、海报、演职员信息，并可直接跳转到资源搜索。

## 站点

「站点」页用于维护 PT 站点账号和站点数据。

### 添加与导入

支持：

- 从内置站点配置添加站点。
- 上传自定义 TOML 站点配置。
- 使用站点配置生成器创建或编辑配置。
- 通过 CookieCloud、PTPP、PT-depiler 或数据备份导入。

站点配置常见字段：

- 用户名、密码、Cookie、User-Agent。
- 代理、镜像地址、站点标签。
- 是否启用、是否签到、是否参与辅种。
- 搜索种子、RSS、浏览器打开等能力开关。

### 站点卡片

站点卡片显示：

- 上传量、下载量、分享率。
- 魔力值、做种数、发布数、HR、邀请。
- 消息、公告、通知。
- 等级、注册时间、最后同步时间。
- 签到状态、站点存活状态。

站点卡片支持多种显示样式，并支持自定义站点图标。自定义图标会优先适配 PNG、GIF、JPG/JPEG、WebP、ICO 等常见格式，失败时回退默认图标。

### 站点操作

站点操作菜单包含：

- 查看详情。
- 刷新站点信息。
- 执行签到。
- 执行辅种。
- 打开首页、搜索页、签到页、个人中心等地址。
- 编辑站点配置。
- 删除站点。

### 筛选和排序

站点页支持：

- 按站点名称、昵称、镜像地址搜索。
- 按存活状态、签到状态、消息、公告、Cookie、UID、Passkey 等条件筛选。
- 按站点类型、标签、用户名、邮箱筛选。
- 用户名和邮箱筛选会统一转为小写聚合与比较，避免大小写不一致造成重复项。
- 按上传、下载、魔力、做种、分享率、更新时间等字段排序。

### 站点详情与时间轴

站点详情页展示账号信息、状态图表、签到记录、等级进度、历史数据和站点相关入口。

站点时间轴可按注册时间、邀请、账号字段等维度查看站点分布，适合整理账号生命周期。

## 仪表盘

「仪表盘」用于查看整体运行情况。

常见模块：

- 总上传、总下载、站点数、P 龄。
- 今日上传、今日下载、月度上传/下载/发种。
- 服务器 CPU、内存、网络速度。
- 站点状态分布、上传下载趋势、做种分布。
- 账号字段统计，例如用户名、邮箱、UID 等。

常用操作：

- 手动刷新仪表盘。
- 触发站点信息更新任务。
- 触发签到任务。
- 开启隐私模式截图。
- 清理缓存。
- 配置图表显示和自动刷新间隔。

## 下载器

「下载」页用于管理 qBittorrent 和 Transmission。

### 添加下载器

需要配置：

- 名称。
- 下载器类型。
- 协议、主机、端口。
- 用户名、密码。
- External Host。
- 种子路径。
- 启用状态。
- 是否参与辅种。

### 下载器卡片

下载器卡片显示：

- 实时上传/下载速度。
- 活跃任务数、总任务数。
- 可用空间。
- 已上传、已下载。
- 当前连接状态。
- 启用和辅种状态。

### 下载器操作

支持：

- 打开种子列表。
- 推送种子。
- 编辑或删除下载器。
- 启用/停用下载器。
- 开启/关闭辅种。
- 执行辅种。
- 打开 qBittorrent 或 Transmission 设置。
- 限速设置。
- 分类管理、标签管理。
- Tracker 替换。

## 种子列表与种子操作

从下载器进入种子列表后，可管理下载器内的种子。

列表能力：

- 状态筛选。
- 分类、标签、站点筛选。
- 搜索和排序。
- 桌面端详情面板。
- 移动端详情 Sheet。
- 实时速度和状态刷新。

单个或批量操作包括：

- 开始、暂停、强制启动。
- 删除种子，可选择是否删除文件。
- 重新校验。
- 重新汇报。
- 修改保存位置。
- 设置分类和标签。
- 自动管理。
- 上传速度限制。
- 分享率限制。
- 超级做种。
- 修改 Tracker。
- 导出 `.torrent`。
- 队列移动到顶部、向上、向下或底部。
- 复制名称、哈希、磁力链接、Tracker、保存路径等信息。

## 搜索

搜索页支持两种模式：

- 搜索信息：从 TMDB 和豆瓣搜索电影、剧集和人物信息。
- 搜索资源：从已配置且支持搜索的站点搜索种子资源。

### 搜索设置

资源搜索可配置：

- 最大搜索站点数，`0` 表示全部。
- 指定搜索站点。
- 是否只使用存活且可搜索的站点。

### 资源结果

资源结果支持：

- 按标题、副标题、大小、做种数、发布时间排序。
- 按站点、促销、分类、分辨率、标签、季、集数筛选。
- HR 过滤。
- 文件大小范围过滤。
- 推送到下载器。

发布时间会解析完整时间并显示为相对间隔，例如 `3小时前`、`2天前`；悬停时显示具体时间。

### 搜索历史

搜索页会保存搜索历史，可快速复用关键词。

## 任务中心

「任务中心」分为计划任务和执行记录。

### 计划任务

支持：

- 普通计划任务。
- 种子迁移任务。

常见任务类型包括：

- 自动签到。
- 批量抓取站点信息。
- RSS 订阅。
- 下载器辅种。
- 种子迁移。
- 自动清理和后台维护任务。

计划任务可配置：

- 任务名称。
- 任务类型。
- Crontab 表达式。
- 启用状态。
- 高级参数。

可对任务执行：

- 立即执行。
- 编辑。
- 删除。

### 种子迁移任务

用于将种子从源下载器迁移到目标下载器。可配置：

- 源下载器。
- 目标下载器。
- 保存路径映射。
- 跳过校验。
- 是否删除源种子。
- 是否启用。

### 执行记录

执行记录显示：

- 任务名称。
- 状态：成功、失败、运行中、等待中、撤销等。
- 开始时间、结束时间。
- 任务 ID。
- Markdown/JSON 详情。

操作规则：

- 运行中或等待中的任务可取消。
- 已完成的任务可删除任务记录。
- 可清理全部执行记录。

## 常见问题

### 登录失败

检查：

- 服务器地址是否带 `http://` 或 `https://`。
- 后端是否已启动。
- 后端是否需要初始化。
- 用户名和密码是否正确。
- Web 端是否被 CORS 或 HTTPS 混合内容限制。

### 站点无法刷新或签到失败

检查：

- Cookie 是否过期。
- User-Agent 是否与 Cookie 来源一致。
- 站点是否需要代理。
- 站点配置 XPath 或解析规则是否失效。
- 服务端日志中的站点错误。

### 搜索不到资源

检查：

- 站点是否启用搜索种子。
- 站点配置是否包含搜索规则。
- 搜索设置是否限制了过少站点。
- 站点是否存活。
- 后端资源搜索接口是否正常。

### 下载器连接失败

检查：

- 协议、主机、端口是否正确。
- 下载器 Web UI 是否启用。
- 用户名和密码是否正确。
- 后端所在机器能否访问下载器。
- 是否需要配置 External Host。

### 日志浮窗一直显示连接中

检查：

- 服务端日志接口是否可访问。
- Token 是否有效。
- 浏览器网络面板中 SSE 是否持续连接。
- 服务端是否返回标准 SSE 或单行 `data: {...}` 日志事件。

### Web 端布局异常

Web 端没有本地红绿灯窗口按钮，也不会预留窗口控制空间。如果出现 header 偏移，刷新页面或检查是否使用了桌面客户端构建。

## 开发运行

### 环境

项目使用 Flutter 和 Dart。

```bash
flutter pub get
flutter analyze
flutter run
```

当前项目依赖包括：

- Riverpod
- Dio
- GoRouter
- Hive
- shadcn_flutter
- Syncfusion Charts
- qBittorrent / Transmission API
- InAppWebView
- window_manager

### 常用命令

```bash
flutter pub get
dart format lib
flutter analyze
flutter run -d chrome
flutter run -d macos
```

### Android HTTP 后端

如果 Android 需要访问 HTTP 后端，确认 `AndroidManifest.xml` 中包含网络权限，并在 `application` 上允许明文流量：

```xml
<uses-permission android:name="android.permission.INTERNET" />

<application
    android:usesCleartextTraffic="true">
</application>
```

### iOS HTTP 后端

如果 iOS 需要访问 HTTP 后端，需要在 `ios/Runner/Info.plist` 配置 ATS 例外：

```xml
<key>NSAppTransportSecurity</key>
<dict>
    <key>NSAllowArbitraryLoads</key>
    <true/>
</dict>
```

### 桌面窗口

桌面端使用隐藏标题栏和自定义窗口控制。macOS/Linux 的窗口按钮位于左侧；Windows 位于右侧。Web 端不显示窗口控制。
