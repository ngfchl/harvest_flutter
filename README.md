# Harvest

Harvest 是面向 PT/PTools/收割机后端的 Flutter 客户端，支持 Web、Android、iOS、macOS、Windows 和 Linux。它把站点管理、数据看板、下载器管理、种子操作、计划任务、影视资讯、聚合搜索、通知与日志排查集中在一个 App 内。

> 本文按现有代码整理为 APP 使用手册。不同后端版本、权限和平台可能会影响可见入口与接口能力。

## 快速开始

### 1. 准备后端

使用前需要先有可访问的收割机/Harvest 后端服务。客户端登录页会要求填写服务器地址，例如:

```text
http://127.0.0.1:8000
https://example.com
```

建议:

- Web 端优先使用 HTTPS 后端，避免浏览器混合内容限制。
- 移动端和桌面端可连接局域网、内网穿透或公网后端。
- 如果后端启用了鉴权，请准备好账号、密码或安全 Token。

### 2. 登录

打开 App 后进入登录页:

1. 填写服务器地址。
2. 输入账号与密码。
3. 登录成功后默认进入「仪表」页。

客户端会保存登录状态、Token 和常用账号记录。后续可在登录历史中切换已保存账号。

### 3. 首次使用建议顺序

1. 到「设置」配置安全 Token、通知渠道、影视 Token、CookieCloud 等基础项。
2. 到「站点」添加站点或导入站点数据。
3. 到「下载」添加 qBittorrent 或 Transmission 下载器。
4. 到「任务」创建自动签到、站点信息更新、辅种、RSS、种子迁移等计划任务。
5. 到「仪表」查看全局数据与服务器状态。

## 界面导航

底部/侧边主导航包含:

- 「资讯」: TMDB 与豆瓣影视资讯。
- 「站点」: PT 站点列表、状态、签到、辅种、配置管理。
- 「仪表」: 总览看板、服务器资源、上传下载趋势、站点统计。
- 「下载」: 下载器配置、实时速度、种子列表入口。
- 「任务」: 计划任务和执行记录。

另有全局入口:

- 搜索页: 影视信息搜索与站点资源搜索。
- 设置页: 系统配置、通知、导入导出、更新等。
- 通知历史: 查看服务端/本地通知。
- 日志中心: 查看 APP 日志和服务端日志。
- 日志浮窗: 在任意页面打开轻量日志窗口。

## 登录与账号

### 服务器地址

服务器地址必须以 `http://` 或 `https://` 开头。切换后端时，建议重新登录以刷新 Token 和本地缓存。

### 登录历史

登录历史用于快速切换曾经登录过的服务器和账号。若服务端地址、账号权限或 Token 已变化，请重新输入登录信息。

### 登出

登出会清理当前认证状态。部分页面缓存会在重新登录后自动刷新。

## 资讯

「资讯」页包含两个来源:

- TMDB: 正在热映、热门电影、即将上映、热门剧集。
- 豆瓣: Top250、排行榜、热门电影、热门剧集。

使用建议:

- 在「设置 -> 影视Token配置」中配置 TMDB/相关授权后，TMDB 内容更完整。
- 在搜索页可以搜索电影、剧集，并查看详情。
- 如果不需要资讯入口，可在「设置 -> 影视资讯」关闭 TMDB 或豆瓣内容。

## 站点

「站点」页用于管理已添加的 PT 站点。

### 添加站点

支持以下方式:

- 添加站点: 从内置站点配置中选择站点。
- 上传配置: 上传自定义 TOML 站点配置。
- 生成配置: 使用站点配置生成器编辑并保存 TOML 配置。
- 数据导入: 在设置页通过备份、CookieCloud 等方式导入。

添加站点时常见字段:

- 用户名、密码、Cookie、UA、代理。
- 启用站点开关。
- 自动签到、辅种任务、搜索种子等功能开关。
- 标签，用于分类筛选。

### 站点卡片

站点卡片会显示:

- 上传量、下载量、分享率。
- 魔力值、做种数、发布数、HR、邀请、消息、公告。
- 等级、注册时间、最后同步时间。
- 签到状态与站点存活状态。

### 站点操作菜单

站点卡片支持操作菜单，常用操作包括:

- 详情: 查看基础信息、状态图表、签到记录。
- 刷新: 更新站点信息。
- 签到: 对未签到站点执行签到。
- 辅种: 提交辅种任务。
- 浏览器: 打开站点首页、签到页、种子页、搜索页、个人中心等。
- 编辑: 修改账号、Cookie、功能开关等。
- 删除: 删除站点记录。

### 站点筛选和排序

站点页支持搜索和筛选:

- 站点状态: 存活、死亡、无站点数据。
- 签到状态: 已签到、未签到、无签到记录。
- 站点类型、标签、功能状态。
- 排序字段: 上传量、下载量、用户名、邮箱、UID 等。

### 站点时间轴

站点时间轴用于按注册时间或注册时长查看站点分布，可筛选、排序和调整显示字段。

## 仪表盘

「仪表」页是总览页面，桌面端和移动端布局不同，但核心内容一致。

### 数据总览

展示:

- 总上传、总下载。
- P 龄、站点数。
- 今日上传/下载。
- 月度上传/下载/发种。
- 站点上传、下载、做种、账号信息分布。

### 服务器状态

展示:

- CPU 占用。
- 内存占用。
- 上传/下载实时速度。
- 可配置刷新间隔与自动刷新。

### 图表设置

仪表盘支持配置:

- 站点状态显示。
- 服务器状态自动刷新。
- 刷新间隔。
- 看板开关列表。
- 增量趋势默认时间范围。

### 清理缓存

仪表盘提供缓存清理入口，可清理站点数据、影视数据、应用版本等缓存。清理后相关页面会重新拉取数据。

## 下载器

「下载」页用于管理下载器。当前代码支持 qBittorrent 与 Transmission 相关能力。

### 添加下载器

需要填写:

- 名称。
- 客户端类型。
- 协议: HTTP 或 HTTPS。
- 主机、端口。
- 用户名、密码。
- External Host。
- 种子路径。
- 启用开关。
- 辅种开关。

### 下载器卡片

下载器卡片展示:

- 实时速度。
- 活跃数、总数、剩余空间。
- 已上传、已下载。
- 种子路径。
- 启用与辅种状态。

### 下载器操作

下载器菜单包含:

- 种子列表: 进入该下载器的种子列表。
- 添加种子: 推送种子到下载器。
- 编辑、删除。
- 执行辅种。
- 设置: qBittorrent/Transmission 设置。
- 限速设置。
- 分类管理、标签管理。

### 刷新设置

可配置自动刷新数据和刷新间隔。若下载器较多或网络较慢，建议适当提高刷新间隔。

## 种子列表与种子操作

从下载器进入「种子列表」后可管理下载器中的种子。

### 列表能力

支持:

- 实时速度栏。
- 状态筛选: 活动、暂停、等待、错误等。

- 排序。
- 桌面端详情面板。
- 移动端详情 Sheet。

### 常用操作

单个或批量种子可执行:

- 删除种子，可选择是否删除文件。
- 重新校验。
- 重新汇报。
- 更改保存位置。
- 分类、标签设置。
- 复制名称、哈希、磁力链接、Tracker 地址、保存路径。
- 自动管理。
- 上传速度限制。
- 分享率限制。
- 超级做种。
- 修改 Tracker。

侧边栏会汇总错误种子，可清理可删除错误种子。删除前请确认是否需要保留文件。

### 计划任务

计划任务可配置:

## 常见问题

### 登录后页面空白或数据为空

检查:

- 后端地址是否正确。
- 当前账号是否有权限。
- Token 是否过期。
- 后端接口是否正常。
- 日志中心是否有 HTTP 或业务错误。

### Web 端连接服务端日志一直显示连接中

检查后端 `/api/auth/logs/stream` 是否返回 SSE 数据。客户端兼容标准 SSE 空行分隔和单行 `data: {...}` 事件。若仍异常，请打开浏览器开发者工具查看网络请求状态。

### 站点无法刷新或签到失败

检查:

- Cookie 是否过期。
- User-Agent 是否与 Cookie 来源一致。
- 站点是否需要代理。
- 站点配置 XPath 是否失效。
- 后端日志中的签到/刷新错误。

### 搜索不到资源

检查:

- 站点是否启用「搜索种子」。
- 站点配置是否包含搜索页规则。
- 搜索设置是否指定了过少站点。
- 站点是否存活。

### 下载器连接失败

检查:

- 协议、主机、端口是否正确。
- 下载器 WebUI 是否启用。
- 用户名密码是否正确。
- 是否需要 External Host。
- 后端所在机器能否访问下载器。

### 种子操作没有生效

检查:

- 当前下载器类型是否支持该操作。
- 种子哈希/ID 是否有效。
- 下载器权限是否足够。
- 操作后刷新列表确认状态。

### 图表数据不更新

检查:

- 站点信息是否已刷新。
- 仪表盘自动刷新是否开启。
- 后端是否有缓存。
- 可尝试清理缓存或手动刷新。

## 开发与平台配置

### Flutter 环境

项目使用 Flutter/Dart 开发。常用命令:

```bash
flutter pub get
flutter analyze
flutter run
```

### Android 网络权限

路径:

- `android/app/src/main/AndroidManifest.xml`
- `android/app/src/profile/AndroidManifest.xml`

在 `manifest` 节点下确认网络权限:

```xml
<uses-permission android:name="android.permission.READ_PHONE_STATE" />
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.ACCESS_WIFI_STATE" />
```

如需访问 HTTP 后端，在 `application` 上设置:

```xml
<application
    android:label="ptools"
    android:name="${applicationName}"
    android:usesCleartextTraffic="true"
    android:icon="@mipmap/ic_launcher">
</application>
```

### iOS HTTP 访问

如果需要访问 HTTP 后端，在 `ios/Runner/Info.plist` 的顶层 `dict` 中加入:

```xml
<key>NSAppTransportSecurity</key>
<dict>
    <key>NSAllowArbitraryLoads</key>
    <true/>
</dict>
```

### macOS 网络权限

在以下文件中确认网络客户端权限:

- `macos/Runner/DebugProfile.entitlements`
- `macos/Runner/Release.entitlements`

```xml
<key>com.apple.security.network.client</key>
<true/>
```
